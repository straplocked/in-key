## Rubber Band Library v3.3.0

- **Website**: https://breakfastquay.com/rubberband/
- **Source**: https://github.com/breakfastquay/rubberband (tag `v3.3.0`)
- **License**: GNU General Public License v2.0 or later (GPL-2.0-or-later)
- **Copyright**: 2007-2023 Particular Programs Ltd.
- **Used for**: Pitch shifting, time stretching and formant preservation (statically linked)

Rubber Band is GPL software, and it is **statically linked into the InKey
binaries**. GPL-2.0-or-later is compatible with InKey's GPL-3.0 license, which
is why InKey can ship with it. As a consequence:

- Any binary distribution of InKey must be accompanied by (or offer) the
  complete corresponding source code under GPL terms.
- Forks that want to distribute InKey under other terms (for example a
  closed-source build) must first obtain a commercial Rubber Band license from
  the copyright holders (https://breakfastquay.com/rubberband/license.html).

Rubber Band is built from its single-file compilation unit
(`single/RubberBandSingle.cpp`), using the built-in FFT and resampler (vDSP on Apple platforms).

## ARA SDK 2.2.0 (optional)

- **Website**: https://www.celemony.com/en/service1/about-celemony/technologies
- **Source**: https://github.com/Celemony/ARA_SDK (tag `releases/2.2.0`)
- **License**: Apache License 2.0
- **Copyright**: Celemony Software GmbH
- **Used for**: ARA2 (Audio Random Access) integration with compatible DAWs

The ARA SDK is only fetched and compiled when InKey is configured with
`-DENABLE_ARA=ON`. It is not part of the default build, and binaries built without
`ENABLE_ARA` contain no ARA SDK code. The `ARA_Examples` submodule (which carries
additional third-party components) is not fetched.
